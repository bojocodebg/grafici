# Графици – Денонощни аптеки „Пулс“

Уеб система за работни графици на служителите (Next.js 16 + MySQL/MariaDB).

## Функции

**Всеки служител (без допълнителни права):**
- преглед на месечния график на своята аптека (само четене) + списък „Моите смени“ с общо часове;
- изпращане на забележки (по избор за конкретна дата) – след изпращане не могат да се редактират/трият;
- подаване на заявки за отпуск (платен, неплатен, болничен, друг) – след подаване не могат да се променят;
- смяна на собствената парола.

**Административна част – права, задавани поотделно на всеки потребител:**

| Право | Какво позволява |
|---|---|
| Администратор | пълен достъп до всичко |
| `schedule.view_all` | преглед на графиците на всички аптеки |
| `schedule.edit` | попълване/редакция на графика, копиране от предходен месец |
| `leave.approve` | одобряване/отказ на отпуски (одобрените се виждат в графика като „О“) |
| `notes.manage` | преглед на всички забележки, отговор, изтриване |
| `users.manage` | създаване/редакция на потребители и техните права |
| `pharmacies.manage` | управление на аптеки и типове смени |

Правата се проверяват на сървъра при всяко действие и промяната им важи веднага.

## Инсталация

Изисквания: Node.js 20+ и MySQL 8 / MariaDB 10.6+.

1. Копирайте `.env.example` като `.env.local` и попълнете паролата на MySQL потребителя (`root`) и базата (`grafici`).
   **Задължително сменете `SESSION_SECRET`** с дълъг случаен низ. При работа през HTTPS задайте `COOKIE_SECURE=true`.
2. Инсталиране и създаване на базата, таблиците и началните данни:
   ```bash
   npm install
   npm run db:init
   ```
   (схемата е и в `sql/schema.sql`, ако предпочитате да я пуснете ръчно)
3. Стартиране:
   ```bash
   npm run build && npm start      # продукция, порт 3000
   npm run dev                     # разработка
   ```
4. Вход: **admin / admin123** – сменете паролата веднага от „Моят профил“.

## Структура

- `sql/schema.sql` – таблици: `pharmacies`, `users`, `user_permissions`, `shift_types`, `shifts`, `notes`, `leave_requests`
- `scripts/init-db.mjs` – създаване на схемата + админ, примерни аптеки и смени
- `lib/` – връзка с БД, сесии (JWT в httpOnly бисквитка), права
- `app/(app)/grafik` – графикът (редактор с избор от прозорец или „четка“ за бързо попълване, покритие по дни, печат A4)
- `app/(app)/zabelezhki`, `app/(app)/otpuski` – забележки и отпуски
- `app/(app)/admin/*` – потребители и права, аптеки, типове смени
